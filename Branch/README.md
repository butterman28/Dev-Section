## Installation

Branch is distributed as a **single self-contained native binary (~16–18 MB)**.  
No runtime or dependencies are required.

Download the correct binary for your platform from:

👉 https://github.com/butterman28/Dev-Section/releases

---

### Linux (x86_64)

```bash
curl -LO https://github.com/butterman28/Dev-Section/releases/download/v1.0.0/branch-linux-x86_64
chmod +x branch-linux-x86_64
sudo mv branch-linux-x86_64 /usr/local/bin/branch
branch --help
```


### Mac os
```bash 
curl -LO https://github.com/butterman28/Dev-Section/releases/latest/download/branch-macos-x86_64
chmod +x branch-macos-x86_64
sudo mv branch-macos-x86_64 /usr/local/bin/branch
branch --help
```
# note: 
- If macOS blocks the binary on first run, remove the quarantine attribute:
```bash
xattr -d com.apple.quarantine /usr/local/bin/branch
```
### Windows

- Windows (x86_64)

- Download branch-windows-x86_64.exe from the releases page

- (Optional) Rename it to branch.exe

- Move it to a directory in your PATH (e.g. C:\Users\<you>\bin)

- Open Command Prompt or PowerShell and run: "branch"
